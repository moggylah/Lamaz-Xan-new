# Lamaz Xan

React/Vite приложение для времени намазов, расписания местной мечети и направления Кыблы.

## Реализовано

- GPS и выбор координат на карте
- автоматический часовой пояс по координатам
- расчёт времени намаза через `adhan`
- выбор метода расчёта и мазхаба Асра
- поиск зарегистрированной мечети и Adhan/Iqamah через My-Masjid
- Фаджр, Восход, Духа, Зухр, Аср, Магриб, Иша
- ночная молитва: показывается начало последней трети ночи
- направление Кыблы и компас телефона
- уведомления по фард-намазам и началу последней трети ночи
- интерфейс на русском, английском, немецком, французском и испанском
- PWA manifest, service worker и иконки Lamaz Xan

## Последняя треть ночи

В приложении ночь считается от Магриба до Фаджра следующего дня. Интервал делится на три равные части. Строка «Ночная молитва» показывает начало последней трети:

`начало последней трети = Фаджр следующего дня - (длина ночи / 3)`

Это ориентир для кыяма/тахаджжуда, а не отдельное обязательное время намаза.

## Запуск

```bash
npm install
npm run dev
```

Vite уже слушает локальную сеть (`host: 0.0.0.0`).

## Уведомления

В настройках можно включить уведомления для каждого фард-намаза и для начала последней трети ночи, а также выбрать напоминание в момент наступления или заранее.

Текущий локальный scheduler работает, пока приложение запущено. Service Worker уже добавлен и готов принимать Web Push, но для гарантированной доставки при полностью закрытом приложении нужен сервер, который хранит push-подписки и отправляет Web Push в нужное время.

На iPhone Web Push следует использовать в установленном на экран «Домой» web app через HTTPS.
